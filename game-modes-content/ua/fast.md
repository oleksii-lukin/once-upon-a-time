# Швидкий режим

Швидша версія гри. Переривання вимкнені, дозволяючи Оповідачу зосередитися на своєму оповіданні без постійних перехоплень. Ідеально підходить для коротких сесій або вивчення ігрового процесу.

## Приклади використання

- "Гравець 1 (Оповідач): 'У далекому королівстві жила юна принцеса з магічними здібностями...' (розігрує карту Принцеса)"
- "Гравець 1: 'Вона виявила стародавню книгу заклинань, сховану в бібліотеці замку...' (розігрує карту Книга)"
- "Гравець 1: 'Книга розкрила пророцтво про дракона, який загрожував королівству...' (розігрує карту Дракон)"
- "Гравець 1: 'Озброївшись цим знанням, принцеса вирушила шукати легендарний меч, здатний перемогти звіра...' (розігрує карту Меч, потім карту Фінал для перемоги)"
