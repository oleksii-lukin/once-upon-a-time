## 🧠 Universal Story Structures & Archetypes

Drawing from sources like MasterClass, Scribophile, and StorytellingDB, here are the most enduring storytelling frameworks:

### 🔹 The 7 Basic Plots (Christopher Booker)
| Plot Type           | Core Theme                          |
|---------------------|-------------------------------------|
| Overcoming the Monster | Hero faces and defeats a great evil |
| Rags to Riches         | Rise from humble to glorious       |
| The Quest              | Journey with obstacles and allies  |
| Voyage and Return      | Travel to strange land, return changed |
| Comedy                 | Confusion resolved into harmony    |
| Tragedy                | Fall due to fatal flaw             |
| Rebirth                | Redemption and transformation      |

### 🔹 Hero’s Journey (Joseph Campbell)
- Call to adventure → Trials → Abyss → Transformation → Return  
- Emphasizes growth, challenge, and inner change.

### 🔹 Character Archetypes
- Hero, Mentor, Shadow, Trickster, Ally, Herald, Guardian
