# Быстрый режим

Более быстрая версия игры. Прерывания отключены, позволяя Рассказчику сосредоточиться на своем повествовании без постоянных перехватов. Идеально подходит для коротких сессий или изучения игрового процесса.

## Примеры использования

- "Игрок 1 (Рассказчик): 'В далеком королевстве жила юная принцесса с магическими способностями...' (разыгрывает карту Принцесса)"
- "Игрок 1: 'Она обнаружила древнюю книгу заклинаний, спрятанную в библиотеке замка...' (разыгрывает карту Книга)"
- "Игрок 1: 'Книга раскрыла пророчество о драконе, который угрожал королевству...' (разыгрывает карту Дракон)"
- "Игрок 1: 'Вооружившись этим знанием, принцесса отправилась искать легендарный меч, способный победить зверя...' (разыгрывает карту Меч, затем карту Финал для победы)"
